# Skill: Pets Records

Aliases: pets, dog, Hulk, Zeus, vet, feeding, walk

## Purpose

Maintain pet profiles, vet logs, feeding schedule, and walks log.

## Run Steps

1. Read `04_Pets/README.md`.
2. Use `04_Pets/Hulk/` or `04_Pets/Zeus/` for dog-specific records.
3. Put vet visits, vaccines, weight, costs, and next due dates in `vet_log.csv`.
4. Put shared walks in `04_Pets/walks_log.csv`.
5. Put feeding changes in `04_Pets/feeding_schedule.md`.
6. Add dated vet or grooming appointments to the calendar when known.

## Dry Run

Show the target pet file, row, and any calendar entry.
