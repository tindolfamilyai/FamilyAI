# Skill: Home Maintenance

Aliases: home, house, repair, maintenance, inventory, warranty, seasonal

## Purpose

Track home repairs, maintenance, inventory, warranties, and seasonal reminders.

## Run Steps

1. Read `05_Home/README.md`.
2. Put recurring tasks and service work in `maintenance_log.csv`.
3. Put break/fix items in `repairs_log.csv`.
4. Put purchases, appliances, serial numbers, and warranties in `inventory.csv`.
5. Put monthly and seasonal reminders in `seasonal_reminders.md`.
6. Add dated service appointments to the calendar when known.
