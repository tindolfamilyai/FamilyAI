# Skill: Inbox Triage

Aliases: inbox, sort, route, classify, organize

## Purpose

Sort unsorted notes, receipts, attachments, and ideas from `_Inbox/`.

## Run Steps

1. Read `_Inbox/README.md` and `_Agent/PROJECT_MAP.md`.
2. Inspect each item in `_Inbox/`.
3. Classify each item by destination domain.
4. Move raw files to `_Attachments/` when they should be preserved as source material.
5. Add summaries, rows, or links to the relevant domain file.
6. Leave ambiguous items in `_Inbox/` with a short note about what needs clarification.
7. Report what moved, what was updated, and what remains.

## Dry Run

List each inbox item, proposed destination, and proposed file updates without editing.

## Safety

Treat receipts, medical files, child records, and account screenshots as sensitive.
