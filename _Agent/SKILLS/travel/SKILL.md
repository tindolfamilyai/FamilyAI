# Skill: Travel Planning

Aliases: travel, trip, vacation, packing, itinerary

## Purpose

Create and maintain trip plans, budgets, packing lists, and related calendar items.

## Run Steps

1. Read `07_Travel/README.md`.
2. Use trip folder naming: `07_Travel/Trips/YYYY-MM_Destination/`.
3. Start from `07_Travel/trip_template.md`, `packing_list_template.md`, and `travel_budget_template.csv`.
4. Add known travel dates to `00_Calendar/YYYY-MM.csv`.
5. Put generated or finalized trip summaries in the trip folder or `_Reports/`.

## Dry Run

Show the folder name, template files, and calendar entries that would be created.

## Safety

Do not book lodging, flights, tickets, or reservations unless the user explicitly asks and confirms the exact action.
