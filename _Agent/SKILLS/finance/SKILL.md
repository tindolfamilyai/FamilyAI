# Skill: Finance Tracking

Aliases: finance, budget, expense, receipt, subscription, savings, bill

## Purpose

Track expenses, budgets, subscriptions, and savings goals without performing financial actions.

## Run Steps

1. Read `06_Finances/README.md` and `_Agent/SAFETY_PRIVACY.md`.
2. Put one-time expenses in `06_Finances/expenses.csv`.
3. Put recurring services in `06_Finances/subscriptions.csv`.
4. Update budget summaries in `06_Finances/monthly_budget.csv` when enough data is available.
5. Update goals in `06_Finances/savings_goals.md`.
6. Put receipts or raw files in `_Attachments/` if preserving the source matters.

## Dry Run

Show the exact finance rows or notes that would be added.

## Safety

Never execute payments, purchases, trades, transfers, account changes, or cancellations.
