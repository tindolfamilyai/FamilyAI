# Skill: Fitness Logging

Aliases: fitness, workout, exercise, run, lift, training

## Purpose

Log workouts and maintain workout plans.

## Run Steps

1. Read `02_Health_Fitness/README.md`.
2. Identify whether the workout belongs to Blake or Melina.
3. For Blake, read `02_Health_Fitness/Workouts/workout_templates.md` and map the log to the best session/exercises.
4. For Blake, append performed rows to `02_Health_Fitness/Workouts/Blake/blake_workouts_performed.csv` only for exercises actually done.
5. For Melina, append to `02_Health_Fitness/Workouts/Melina/melina_workouts.csv`.
6. If Blake session cannot be inferred, use `Session=Unclassified` and preserve user wording in `Notes`.
7. Keep `_Archive/02_Health_Fitness/Workouts/Blake/blake_workouts_2026-05-04_to_2026-07-26.csv` as historical plan context unless explicitly asked to edit it.
8. Update `02_Health_Fitness/Workouts/workout_plan.md` when the plan itself changes.
9. Use only user-provided facts for sets, reps, load, distance, duration, intensity, and notes.
