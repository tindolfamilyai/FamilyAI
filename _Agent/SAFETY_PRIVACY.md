# Safety And Privacy

This hub contains family, child, health, pet, home, finance, and social media information. Treat it as private by default.

## Hard Limits

Agents must not:

- Execute purchases, payments, transfers, trades, withdrawals, deposits, or account changes.
- Make medical, legal, financial, or safety-critical decisions for the family.
- Share sensitive family, child, medical, school, account, or finance data externally unless explicitly asked and clearly necessary.
- Store passwords, API keys, access tokens, Social Security numbers, or full payment card numbers in this folder.
- Delete source records unless the user explicitly asks.

## Allowed Help

Agents may:

- Organize, summarize, and route information.
- Draft checklists, reminders, plans, messages, and reports.
- Append factual rows to logs from user-provided information.
- Flag missing details, conflicts, or follow-up items.
- Recommend that the user consult a professional for medical, legal, tax, or financial decisions.

## Sensitive Areas

- `03_Kids/`: child health, school, daycare, sizes, and milestones.
- `06_Finances/`: expenses, budgets, subscriptions, and goals.
- `08_Social_Media_Orlando_Theme_Park_Family/`: brand, analytics, compensation, and account planning.
- `_Attachments/`: receipts, screenshots, documents, and raw source files.

## External Actions

Before using external tools, uploading files, sending messages, or creating public content, confirm the exact action with the user unless it is clearly read-only and required for the request.
